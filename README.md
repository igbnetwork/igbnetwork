### 🏢 Sobre nosotros

**IGB Network** (IGB NETWORK, S.A.P.I. de C.V.) es un fondo de inversión y agencia de consultoría tecnológica con base en Querétaro, México, que atiende clientes en **Estados Unidos, México, Puerto Rico y LATAM**.

Diseñamos y construimos ecosistemas web, agentes de IA, automatización de procesos y sistemas de trading algorítmico para empresas que quieren escalar con tecnología.
