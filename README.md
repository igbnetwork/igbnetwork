### 🏢 Sobre nosotros

**IGB Network** (IGB NETWORK, S.A.P.I. de C.V.) es un fondo de inversión y agencia de consultoría tecnológica con base en Querétaro, México, que atiende clientes en **Estados Unidos, México, Puerto Rico y LATAM**.

Diseñamos y construimos:

- 🌐 Ecosistemas web y funnels de marketing
- 🤖 Chatbots y agentes de IA (voz y texto)
- ⚙️ Automatización de flujos de trabajo (n8n + GoHighLevel)
- 📊 Sistemas de trading algorítmico e IA financiera
- 🧩 Plataformas a medida para pequeñas y medianas empresas
